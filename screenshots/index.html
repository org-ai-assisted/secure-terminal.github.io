Highlights

The shots that best show what secure-terminal does: the review bar in both directions, the four display modes, and the combined attack board reduced to inert ASCII.

Every display mode, every board

The same attack boards from the comparison, each rendered by secure-terminal in every mode it offers: CLI Box, Show and Detail, plus TUI Box and Show. This is the full render matrix, for a human to scan for a broken or empty capture.

The combined board

every attack class at once - title injection, alt screen, DEC line-drawing, an SGR-hidden SECRET, plus homoglyph, zero-width, bidi and foreign bytes.

Bidi override (Trojan Source)

bidirectional controls that reorder how a line renders (CVE-2021-42574).

Homoglyph look-alikes

non-ASCII characters shaped like ASCII - a Cyrillic a, a Greek o - that make a fake command read as legitimate.

Zero-width / invisible

characters that draw nothing, so a line can carry bytes you never see.

Unicode names

non-ASCII bytes named inline as their Unicode code point.

Title / tab hijack

an OSC 0/2 sequence that would silently rename a normal window or tab.

Escape repaint

cursor and erase sequences that would rewrite or conceal output already on screen.

Alt-screen forge

a switch to the alternate screen that would paint a fake dashboard and leave no trace.

Notification spoof

an OSC 9 / 99 sequence that would raise a desktop notification carrying attacker text.

Contrast guard

colour that a program cannot use to hide text against the background.

Random bytes

plain random data fed straight to the terminal.

ANSI art

legitimate SGR colour art, kept readable.

Truecolour gradient

a dense per-cell truecolour gradient.

Real-tool compatibility

secure-terminal running ordinary command-line tools, output rendered normally - the everyday case, not an attack. Full detail on the compatibility page.
